# Optional fallback: raw TFLite Micro model

`model_data.cc` / `model_data.h` in this folder are the INT8 model exported
as a C byte array, generated by `src/quantize.py`.

**You probably don't need these for the UNO Q.** The primary deployment
path (see `../uno_q_linux/`) runs the model with the full TensorFlow Lite
Python runtime on the UNO Q's Linux/Qualcomm side, since it has 2GB of RAM
-- no need to fight TensorFlow Lite Micro's more limited op support and
manual memory-arena tuning.

Keep these files around only if you later port this project to a true
bare-metal microcontroller with no Linux side (e.g. a plain ESP32-CAM
without a companion Linux SoC). In that case you'd pair them with the
TensorFlow Lite Micro library and write an inference loop similar to
TFLite Micro's official `person_detection` example, using
`waste_classifier_model` / `waste_classifier_model_len` as the model buffer.
